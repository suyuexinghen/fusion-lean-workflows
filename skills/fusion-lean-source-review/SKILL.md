# C · 从来源得到独立预期

1. 从协调者接收中性题面、固定来源和版本。核对版面、公式、量纲、约定与适用域，登记哪些材料共享底稿。按[岗位协作](../fusion-lean-workflow/references/role-practice.md)控制作答前可见信息。
2. 在接触候选之前固定推导、预期、一个正常输入和一个区分解释的错例。为 Lean 写明假设和结论，为 compute 写明坐标、单位、有判别力的观测量和容差依据。
3. 比较候选时把原文、独立预期与实现差异分别定位。修订预期时保留原版及修订理由。实际签审人自行登记名字和审过的版本。

任务的领取、交付和所有权见[队列手册](../fusion-lean-workflow/references/queue.md)。
