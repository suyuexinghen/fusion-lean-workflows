# 迁移演练：日报中零值与未上报

这是一组教学用的合成数据，展示单仓、脚本和数据字典如何承担与 Fusion Lean 相似的职责。源合同规定 A 供应方用空字段表示未上报，B 供应方用 `NR`。两家都允许有效数值 0。业务使用者问：“计算平均值时，到底有哪些天算入了分母？”

## 固定独立答案

输入 A 有三天，读数依次为 0、12、空。按合同有两天有效，平均 6。输入 B 有四天，读数依次为 4、0、18、NR。有三天有效，平均 22/3。数据字典应给出值、分母和适用合同。历史实现除声明的缺失标记外还丢弃字符串 `0`，会得到 A 一天有效、平均 12，B 两天有效、平均 11。两个错误均有数值输出，单测“文件可解析”无法检出。

从技能目录运行以下命令。输出依次列总行数、有效行数和平均值，数值以十进制字符串报告。B 的循环小数按 Python Decimal 的精度显示。

```sh
python3 examples/replay.py --rule legacy
python3 examples/replay.py --rule candidate
python3 examples/replay.py
```

第一条预期退出 1，显示旧规则处理零值有误。第二条预期退出 0。第三条同时对照新旧规则，要求两家都能击中旧错并通过新结果，预期退出 0。脚本使用同一份独立期望。样本 B 展示跨供应方迁移的做法，两个教学样本均公开；真实项目需要另取未用于设计的供应方资料才能声称盲测通过。[可执行演练](../examples/replay.py)

## 把演练换成自己的项目

1. 数据负责人从合同固定适用版本、字段、缺失标记和两组手算值。实现者可同时盘点公开入口。第一个里程碑要交付同一输入经正式导入命令至日报的结果。
2. 编辑让读者从日报说明回答分母和零值算不算。独立 agent 在看到实现或作者解答前按合同作答；若说明只写“忽略无值”，请它指出具体误读及证据，回交作者修订并复审。
3. 维护者根据复发提出一项工作流规则：“新接入来源必须声明缺失标记，并在冻结样例中同时给出合法零和缺失值。”实验时固定数据、预期和业务实现；比较采用规则前后的验收套件能否抓到植入的旧错，并检查正确实现仍能通过。运行 `python3 examples/replay.py --compare-gates` 单独评估**验收规则的修复**。旧结构门在两个供应方上都接受了丢零的实现；新合同门在 2/2 个植错样本上拒绝、在 2/2 个正确样本上接受，预期退出 0。团队能否在下一次接入中自行形成同样的好测试，仍需用一份新合同检验。
4. 复盘时同时看有证据的来源数/已接入来源数、被独立读者正确解释的指标数/应审指标数、错误在不同供应方版本的复发情况。若在新合同下一次仍漏掉零值，保留失败报告，检查问题是失效的测试生成规则、规格抽取还是报告说明。决定采用、保留候选或回退后，将证据链接交回初始问题。
