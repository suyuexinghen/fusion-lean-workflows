# Goal · 在同一目标内接续阶段

1. 恢复用户的总体终点、已授权范围、当前版本、队列和最后通过的检查。有同名图时先读取在途任务、历史和原回执，使用既有稳定任务 ID。
2. 根据实际依赖领取或安排任务，固定并复跑证据。交付后再领授权范围内的就绪项。批末按[跨批回执](../fusion-lean-workflow/references/continuation.md)处理复用、装入、等待、收口或待裁定。
3. 对照前次[健康观察](../fusion-lean-workflow/references/health.md)，判断复发与待验问题。逐项核对总目标所需的可取回产物、实测和签审，明确外部恢复条件。

任务的领取、交付和所有权见[队列手册](../fusion-lean-workflow/references/queue.md)。
