# literature · 管理本地聚变文献

1. 从项目配置确认出版书、现行自撰书及各论文库的数据库与正文根。用只读连接按题名、ISBN、规范化 DOI 或已配置的全文索引定位。自撰书目以现行清单和正文目录为范围，书库 ID 与正文路径逐项匹配。
2. 打开原件，用题页核对作者、版次、年份或论文版本。关键词只作线索；涉及公式、图表与页码时看 PDF 版面。入库、去重、修复索引时先在隔离副本验证读写路径、清单和正文的一致性。
3. 交付本地 ID 或 DOI、可读原件路径、文件摘要、版次和可复查的章/节/式号。给登记有而正文缺失的条目标出缺件。资料库持有原件，项目固定必要的来源和定位。

任务的领取、交付和所有权见[队列手册](../fusion-lean-workflow/references/queue.md)。
