# judge · 独立作答并审到固定稿件

1. 确认独立性与可见材料。从中性题面和原始来源形成推导、适用条件和辨错输入。在接触候选、作者预期和同题旧卡之前，提交或计算摘要，冻结答案。
2. 对照固定稿件，逐条判断引文是否支持主张、前提与数值是否一致。发现差异时给出原句位置、受影响的判断和能验证修订的条件。
3. 复审实际终稿。裁决记录受审 Git 版本、路径和内容摘要，并附修订解决的差异与剩余缺口。人类签审由签审者登记。[终稿归属案例](references/experience/final-draft.md)

任务的领取、交付和所有权见[队列手册](../fusion-lean-workflow/references/queue.md)。
