# editor · 写一篇读者能独立使用的词条

1. 给出一个读者要做的具体判断、用到的约定，以及能复算的输入、步骤与结果。说明边界和会改变结论的前提。
2. 逐句检查书页、固定 Lean 声明和实际数值运行。对每条主张标明实读来源与位置，区分实例读数、一般结论和物理解释。
3. 提交稿件。独立 judge 先接收读者题与原始资料，之后才接收固定稿和作者答案。退修按问题 ID 指到正文改动，并交回绑定新版本的审读。

任务的领取、交付和所有权见[队列手册](../fusion-lean-workflow/references/queue.md)。
