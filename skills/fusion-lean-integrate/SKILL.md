# A · 从独立交付汇成阶段证据

1. 定位当前阶段、共享写集、候选和实际下游。按 B 的公开签名和 C 的独立预期逐一对照量词、前提、单位、适用域和结论。S 类陈述和 P 类已证命题使用各自的验收口径。
2. 固定依赖和候选提交，从公共入口重放一般用例、边界与错例，核对声明所依赖的公理及导入。数值轮按运行 ID 绑定原始输入、软件和误差，再交 evidence 独立复跑。
3. 将目标、命令、预期、实得、缺件和 Git 引用交给下游。逐项登记实际消费、独立审读和具名签审。候选版本改变后，重放受影响的检查。

任务的领取、交付和所有权见[队列手册](../fusion-lean-workflow/references/queue.md)。
