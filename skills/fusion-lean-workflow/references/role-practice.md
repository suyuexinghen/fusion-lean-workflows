# 岗位与经验卡

队列任务按 `role` 领取。reader 是队列外的协作角色，goal 与 evolve 负责阶段接续和改进。

| 入口 | 考察的决定 |
|---|---|
| [A / integrate](../../fusion-lean-integrate/SKILL.md) | 公共入口、固定候选与阶段回执 |
| [B / formalize](../../fusion-lean-formalize/SKILL.md) | 声明、证明、反例和消费例 |
| [C / source-review](../../fusion-lean-source-review/SKILL.md) | 独立来源、前提与预期 |
| [compute](../../fusion-compute/SKILL.md) | 上游软件、固定算例、数值误差 |
| [literature](../../fusion-lean-literature/SKILL.md) | 书目、原件、版次、缺件和索引 |
| [editor](../../fusion-lean-editor/SKILL.md) | 读者问题、可核稿件、引文 |
| [evidence](../../fusion-lean-evidence/SKILL.md) | 冻结回放、正反对照与复发 |
| [judge](../../fusion-lean-judge/SKILL.md) | 盲答、裁决与固定终稿 |
| [reader](../../fusion-lean-reader/SKILL.md) | 模拟首答、实际阅读路线与卡点 |
| [goal](../../fusion-lean-goal/SKILL.md) | 跨阶段终点与后继批次 |
| [evolve](../../fusion-lean-evolve/SKILL.md) | 取题、规则试验与跨候选复核 |

独立作答者从协调者收中性题面、冻结来源和输入。若完整队列验收描述有答案，先只传任务 ID、修订、归属和技能入口。确认独立答案已冻结，再开放实现、旧卡和作者候选。不同会话代号由实际不同的执行上下文使用。

遇到改变下一次决定的事实，在当班岗位下留卡，写明触发条件、原判断与实得、适用范围、固定证据和下一次能改变结论的试验。交接时附业务证据与经验卡固定引用。相同经验可复用，遇到反例就收窄或撤回。以下三张公开改写卡分别展示声明覆盖、回放规则和稿件归属。
